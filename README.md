# Sham Cash - محفظة إلكترونية لتحويل واستقبال الأموال

## وصف المشروع
تطبيق **شام كاش** هو محفظة إلكترونية تسمح للمستخدمين بتحويل واستقبال الأموال بسهولة وأمان. يدعم التطبيق:
- تسجيل الدخول وتسجيل المستخدمين.
- تحويل الأموال بين المستخدمين.
- عرض رصيد الحساب وسجل التحويلات.
- إشعارات فورية عند استلام أو إرسال أموال.

## التقنيات المستخدمة
- **Frontend**: React Native (Expo)
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **Authentication**: JWT
- **Testing**: Jest (Frontend), Mocha (Backend)

## كيفية التشغيل

### متطلبات النظام
- Node.js (v16 أو أعلى)
- MongoDB (يمكن استخدام MongoDB Atlas)
- Expo CLI (للتطوير على الجوال)
